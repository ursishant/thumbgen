# Typography & Color Language

This guide specifies the exact typography standards, distress treatments, and color formulas used across high-CTR documentary and video essay packaging.

---

## 1. Typography System

### Hierarchy & Function

```text
[ 1. Giant Background Headline ]   →  1-3 words (Behind subject, sets topic & tension)
[ 2. Tactile Foreground Badge ]     →  Alternative hook (Taped note, stamp, or sticker)
[ 3. Technical Micro-Copy ]         →  Coordinates, dates, case numbers (Subtle realism)
```

### Font Pairings

| Role | Recommended Fonts | Attributes | Sample Usage |
| :--- | :--- | :--- | :--- |
| **Headline Hook** | Bebas Neue Pro, Anton, Impact, Druk Wide Bold, Futura Bold Condensed | All Caps, Ultra-Condensed, Tracking -20 to -40 | `WHO PAYS?`, `GENIUS?`, `LEGACY OVER?`, `AI IS COOKED` |
| **Dossier & Labels** | Courier Prime, Special Elite, American Typewriter, OCR-A | Monospaced, distressed ink typewriter feel | `SUBJECT: EPSTEIN, J.`, `CASE FILE: 1988`, `VIMAL` |
| **Stamp Badges** | League Gothic, DIN Condensed Bold, Champion Gothic | Framed inside a stroke box, rotated -2° to 4° | `SPECIAL REPORT`, `CONFIDENTIAL`, `FILES LEAKED` |
| **Technical Data** | Space Mono, Roboto Mono, Helvetica Neue Regular (Small) | Clean, precise, tracked out (+100) | `52.1 N 13.4 E`, `Faster. Cheaper. More reliable.` |

### Text Distressing & Effects
1. **Halftone Raster on Text**: Apply a color halftone filter (Radius: 4-6px) to the outer edges or drop shadow of giant headlines to evoke newsprint printmaking.
2. **Ink Bleed**: Soften razor-sharp digital edges with a 0.5px Gaussian Blur + Threshold pass to simulate physical letterpress bleeding into paper fibers.
3. **Paper Tear Badges**: Place text on an irregular torn paper background with subtle inner shadows and fiber fringes.
4. **Tape Anchor**: Add semi-transparent duct tape or masking tape over the corners of text blocks with realistic creases.

## 2. Color Palettes

### Palette 1: The Documentary Power Triad (Most Used)
The definitive look for corporate empires, billionaire profiles, and financial crises:

| Role | Color Name | Hex Code | Purpose |
| :--- | :--- | :--- | :--- |
| **Primary Base** | Warm Ivory / Newsprint | `#F4EFEA` | Textured paper background |
| **Dark Base** | Carbon Black / Charcoal | `#121212` | High-contrast shadows, text |
| **High-Voltage Accent** | Blood Crimson Red | `#C8102E` or `#B81D24` | Giant text, tape, stamps, charts |
| **Secondary Accent** | Sepia / Vintage Paper | `#D8C49D` | Manila folders, polaroid frames |

### Palette 2: The Moody Detective / Noir Chamber
For covert operations, backroom deals, and psychological dramas:

| Role | Color Name | Hex Code | Purpose |
| :--- | :--- | :--- | :--- |
| **Dominant Canvas** | Deep Wine Burgundy | `#320B10` to `#1D0508` | Vignetted wall background |
| **Key Text & Lights** | Cream White | `#FDFBF7` | Clean headline typography |
| **Shadow Tone** | Pitch Black | `#090909` | Deep shadows, suit fabrics |
| **Tension Element** | Signal Red | `#E50914` | Conspiracy thread, warning labels |

### Palette 3: The Electric Whistleblower (High-CTR Pop)
For urgent tech leaks, breaking exposés, and modern scandals:

| Role | Color Name | Hex Code | Purpose |
| :--- | :--- | :--- | :--- |
| **Base Accent** | Electric Royal Cobalt | `#0038FF` | Bold background geometric blocks |
| **Alert Element** | Acid / Neon Lime | `#CCFF00` | Peel-off stickers, speech bubbles |
| **Contrast Neutral** | Crisp White | `#FFFFFF` | Sticker borders, crisp headlines |
